## 최근 작업: Firebase 회원 인증 및 공지 관리자 권한

- `pages/login.html`에 공지 페이지 디자인을 따른 로그인·회원가입 화면을 추가했다. 회원 정보는 Firebase Authentication/Firestore를 사용하며 아이디 중복은 트랜잭션으로 재확인한다.
- 공통 헤더에 로그인 링크와 인증 상태 환영 문구/로그아웃을 연결하고 데스크톱 메뉴에 공지사항 링크를 추가했다.
- 공지 UI는 관리자에게만 글쓰기·수정·삭제 동작을 표시하고, `firestore.rules`도 관리자 문서의 `role`로 쓰기를 제한한다. 공개 조회수 증가는 조회수 필드만 1 증가하도록 허용한다.
- 관리자 Auth 계정 및 `users/{uid}`·`usernames/admin` 프로필은 Firebase Console에서 수동 등록해야 한다. Firebase 계정 비밀번호 최소 길이 때문에 요청된 4자리 비밀번호는 사용할 수 없다.
- 정적 코드 검토만 수행했으며, Firebase Console 설정·규칙 게시·브라우저 동작은 아직 확인하지 않았다.
