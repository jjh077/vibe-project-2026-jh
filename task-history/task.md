## 이전 작업 요약

`curr-task/001/promet.txt`의 첫 작업 요청은 첨부된 데스크탑 화면을 기준으로 기본 화면을 구현하는 것이었다. 데스크탑을 우선하고, 이미지는 만들지 말고 이미지가 들어갈 박스만 구성하며, README가 지정한 CSS 파일과 상단 영역을 포함한 HTML 기본 구조를 만들도록 요청했다. 참고 캡처는 `curr-task/001/dt.png`, `mob.png`에 있다.

현재 저장소에는 다음 기본 화면이 이미 구현되어 있다.

- `index.html`: 한국어 문서 기본 구조, 헤더(주요 메뉴·텍스트 로고·검색/마이페이지/장바구니/언어 버튼), 메인 배너 자리와 페이지 표시, 베스트 상품 제목·설명·4개 이미지 자리
- `css/variables.css`: 색상·타이포그래피·간격·모서리·전환·콘텐츠 폭 변수
- `css/reset.css`: 기본 요소 초기화, 포커스 표시, 모션 감소 설정
- `css/components.css`: 아이콘 버튼과 이미지 플레이스홀더
- `css/main.css`: 헤더·배너·베스트 상품 레이아웃 및 모바일 미디어 쿼리

`index.html`은 위 CSS 네 파일을 변수, 리셋, 컴포넌트, 메인 스타일 순서로 연결한다. 이미지 파일을 직접 만들거나 실제 이미지로 대체하지 않고 플레이스홀더를 사용하고 있다. `images/`에는 기존 리소스가 있으나 이전 요청의 이미지 자리 구성 범위에는 사용하지 않았다.

## 최근 작업: 히어로 상단 메뉴 및 화살표 다듬기

`curr-task/001/promet.txt`의 상세 프롬프트와 첨부 데스크톱/모바일 시안을 반영했다.

- `index.html`: 데스크톱 3분할 헤더와 모바일 2단 헤더, 햄버거 메뉴, 카테고리 더보기, 4장 히어로, 베스트 상품 섹션을 구성했다. 이미지에는 `images/used/`의 제공된 데스크톱·모바일 자산을 사용했다. 자동 재생 제어 버튼은 사용자 요청에 따라 제거했다.
- `css/variables.css`, `css/main.css`, `css/components.css`, `css/reset.css`: 기존 스타일 구조를 유지하며 데스크톱 헤더/풀뷰포트 히어로, 768px 이하 모바일 헤더 및 이미지 아트 디렉션, 고정된 양쪽 화살표와 하단 인디케이터를 구현했다. 화살표는 배경 원 없이 10% 크게 표시하고 데스크톱 호버 시 페이드 인/아웃한다.
- `js/main.js`: 자동 순환, 이전·다음·페이지 버튼, 키보드 방향키, 포인터 스와이프, 모션 감소 설정, 모바일 카테고리 확장 및 접근성 있는 메뉴 드로어를 구현했다.

### 검증 상태

- 통합 브라우저에서 320px, 390px, 768px, 769px, 1024px, 1440px 폭을 확인했다. 가로 넘침과 데스크톱 헤더 요소 겹침은 발견되지 않았다.
- 데스크톱 및 모바일용 배너 이미지 로드, 뷰포트 높이 히어로, 화살표/인디케이터 분리, 이전/다음·키보드·스와이프 전환, 자동 순환, 카테고리 확장, 메뉴 열기·Escape 닫기·스크롤 잠금 및 포커스 복귀를 브라우저에서 확인했다.
- 브라우저 콘솔 오류는 확인되지 않았다. 별도 빌드/단위 테스트는 없는 정적 HTML/CSS/JavaScript 프로젝트다.
- 추가 조정에서 자동 재생 버튼 부재, 데스크톱 포인터 진입/이탈에 따른 화살표 페이드 표시/숨김, 투명 화살표 배경과 10% 확대를 확인했다.
- 최신 조정에서 데스크톱 화살표 크기를 20% 추가 확대하고 모바일에서는 화살표를 숨겼다. 모바일 `.hero__inner`의 공통 gutter가 풀블리드 영역에 다시 적용되던 원인을 바로잡아 히어로·트랙·슬라이드 폭이 화면 너비와 일치하도록 수정했다.
- 브라우저에서 모바일 배너 폭 375px, 트랙/첫 슬라이드 폭 375px, 이미지 로드, 모바일 화살표 숨김 및 가로 넘침 없음, 데스크톱 화살표 크기 73.9px(이전 61.6px 대비 1.2배), 화살표 hover 표시/이탈 시 숨김을 확인했다.
- 최신 요청에서 데스크톱 히어로 화살표를 50% 추가 확대하고 모바일 햄버거를 정돈했다. 화살표 변수는 `--space-arrow-size: 6.93rem`, `--space-arrow-icon: 0.99rem`으로 설정되어 있으며 모바일 화살표는 계속 숨긴다.
- 햄버거는 24×24px SVG 아이콘으로 정리하고 세 선을 각각 20px로 맞췄다. 메뉴가 열리면 위·아래 선이 가운데에서 교차해 닫기 아이콘이 되며 가운데 선은 숨긴다.
- 브라우저에서 390×844 모바일 화면 기준 버튼 32×32px, 햄버거 SVG 24×24px 및 각 선 20px, 메뉴 열기/닫기와 Escape 닫기, 모바일 화살표 숨김을 확인했다. 프로젝트에 실행 가능한 단위 테스트 파일은 없다.

## 최근 작업: 모바일 메뉴 드로어

- `index.html`: 모바일 메뉴를 로그인 안내 헤더, 로그인/회원가입/주문조회 버튼, 카테고리 목록과 커뮤니티 아코디언, 한국어·영어 국기 버튼으로 구성했다. 국기 이미지는 `images/img-mob-menu/dayand-mob-95.png`(한국), `dayand-mob-88.png`(미국)을 사용한다.
- `css/main.css`, `css/variables.css`: 흰색 전체 높이 드로어(최대 450px), 왼쪽에서 슬라이드하는 300ms 전환, 상단 연회색 영역, 버튼/포인트 배지, 메뉴 및 언어 선택 상태를 추가했다. 배경 딤은 시안에 맞춰 두지 않았다. 769px 이상에서는 드로어와 햄버거를 숨긴다.
- `js/main.js`: `aria-expanded`/`aria-hidden` 및 `inert`, 스크롤 잠금, 닫기 버튼·Escape, 포커스 이동/복귀, 커뮤니티 아코디언, 국기 선택 상태를 연결했다. 데스크탑으로 크기를 변경하면 드로어를 닫는다.
- 통합 브라우저에서 390px 모바일, 경계 폭 768px 및 769px을 확인했다. 플래그 자산 로드, 드로어 열기·닫기, Escape, `aria-hidden`/`inert`, 스크롤 잠금, 포커스 복귀, 아코디언, 언어 선택 상태가 동작했다. 769px에서는 햄버거와 드로어가 숨겨지고 스크롤 잠금이 해제된다.
- Node.js가 환경에 없어 `node --check`는 실행할 수 없었으나, 브라우저에서 페이지 스크립트와 상호작용을 검증했다.
- 인증/주문조회 목적지는 프로젝트에 제공되지 않아 해당 버튼은 UI만 구성했다. 언어 버튼은 선택 상태만 바꾸며, 전체 페이지 번역 리소스나 언어 전환 기능은 아직 연결되지 않았다. 커뮤니티 하위 항목은 현재 베스트 상품 섹션으로 연결되는 기본 링크다.

### 다음 작업 참고

- 모바일 드로어 인증/주문조회 연결, 실제 다국어 전환, 커뮤니티 하위 항목의 올바른 목적지는 후속 기능 작업 시 확인한다.
- 추가 이미지 생성이나 외부 라이브러리 도입은 하지 않았다.
