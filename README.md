# README

## 1. 프로젝트 안내

본 프로젝트는 기존 웹사이트의 구조와 디자인을 기반으로 UI/UX 개선 및 프론트엔드 개발을 진행하는 프로젝트입니다.

AI 에이전트는 작업을 시작하기 전에 프로젝트의 파일 구조와 기존 코드를 분석하고, 프로젝트의 목적과 개발 환경을 충분히 이해해야 합니다.

## 2. 작업 이력 및 필수 문서 확인

새 작업을 시작할 때 다음 순서로 문서를 확인합니다.

1. `task-history/task.md`가 있으면 먼저 읽어 이전 작업 내용과 현재 구현 상태를 파악하고, 이미 완료된 작업을 불필요하게 반복하지 않습니다. 파일이 없으면 이력 확인을 건너뜁니다.
2. `spec-kit/AGENTS.md`를 읽고 UI/UX 및 프론트엔드 개발 지침을 확인합니다.

해당 문서에는 UI/UX Designer 및 Frontend Developer의 역할, 디자인 기준, 개발 규칙, 반응형 구현, 접근성, 코드 관리 및 검수 기준이 통합되어 있습니다.

모든 설계 및 개발 작업은 해당 문서의 지침을 준수합니다.

작업이 끝나면 `task-history/task.md`를 갱신하여 완료한 작업, 수정한 주요 파일, 남은 작업과 확인하지 못한 항목을 기록합니다. 이력은 이후 작업에 필요한 현재 상태를 간결하게 유지합니다.

## 3. 프로젝트 작업 원칙

- 기존 프로젝트의 기술 스택과 코드 구조를 우선적으로 유지합니다.
- 기존 웹사이트의 디자인, 레이아웃 및 주요 기능을 임의로 변경하거나 삭제하지 않습니다.
- 제공된 디자인 시안과 참고 자료를 충분히 분석한 후 작업합니다.
- 데스크탑, 태블릿, 모바일 환경을 모두 고려하여 구현합니다.
- 요청하지 않은 기능이나 라이브러리를 임의로 추가하지 않습니다.
- 기존 기능에 영향을 줄 수 있는 코드를 수정할 경우 관련 부분을 함께 검토합니다.
- 작업 결과는 실제 실행 및 화면 검증을 통해 확인합니다.

## 4. 작업 진행 및 결과 보고

작업은 다음 순서로 진행합니다.

1. 요청사항 및 관련 문서 확인
2. 기존 소스 코드와 구조 분석
3. 작업 범위 및 수정 대상 파악
4. 설계 및 개발 진행
5. 기능 및 반응형 화면 검증
6. 변경 사항과 테스트 결과 보고

작업 완료 후에는 수정한 파일, 주요 변경 내용, 테스트 결과 및 미확인 사항을 간결하게 정리합니다.

## 5. 지침 우선순위

프로젝트 작업 시 다음 순서를 기준으로 판단합니다.

1. 사용자가 현재 작업에서 명시한 요구사항
2. `spec-kit/AGENTS.md`의 상세 설계 및 개발 지침
3. 기존 프로젝트의 기술 구조와 구현 방식

지침 간 충돌이 발생하면 임의로 판단하여 기존 기능을 훼손하지 말고, 충돌 내용을 확인하고 설명합니다.
