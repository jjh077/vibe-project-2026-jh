[ 공지사항 게시판 생성 프롬프트 ]
- 첨부: 게시판 각 화면(4가지)
-프롬프트(원본)
첨부된 화면과 동일하게 공지사항 게시판을 만들거야. DB없이 로컬스토리지로 개발할거야. 개발후 파이어베이스 DB로 마이그레이션 할 예정이야. 따라서 localstorage_to_firebase_guidelines.md 파일 지침에 따라 개발 구현해야해.

-프롬프트(수정:클로드)
첨부된 4개 화면(목록 / 상세 / 작성 / 수정)과 동일한 UI로 공지사항 게시판을 만들어줘.
DB 없이 localStorage로 개발하고, 이후 Firebase(Firestore)로 마이그레이션할 예정이므로
반드시 localstorage_to_firebase_guidelines.md 지침을 먼저 읽고 그대로 따라 구현해.

[저장 구조]
- 데이터 접근은 Repository 계층(getList, getById, create, update, delete, increaseViews)으로 분리하고,
  UI 코드에서 localStorage를 직접 호출하지 마. (Firebase 전환 시 이 계층만 교체)
- 모든 메서드는 async(Promise) 반환으로 작성.
- 문서 필드: id, category(공지/이벤트), isImportant(필독), title, author, content,
  attachment(name, size), views, createdAt(ISO 문자열). 
- 번호는 저장하지 말고 조회 시 계산해. (고정 공지 제외, 최신순 내림차순)
- 초기 샘플 데이터 7건을 시드로 넣어줘 (화면의 제목/작성일/조회수 기준).

[목록]
- 상단 "전체 N건", 탭(전체보기/공지사항/이벤트) 필터, 제목+내용 검색(select + input + 검색 버튼).
- 필독 글은 상단 고정, 번호 칸에 "공지" 배지, 제목 앞에 "필독" 태그.
- 3일 이내 글은 [NEW], 첨부파일이 있으면 클립 아이콘 표시.
- 페이지당 10건 페이지네이션(이전/다음 포함), 글쓰기 버튼.

[상세]
- 구분/필독 배지, 제목, 작성자, 작성일, 조회수(진입 시 +1), 첨부파일(이름·용량).
- 본문 렌더링: XSS 방지를 위해 텍스트는 escape 처리하고 줄바꿈만 반영.
  (※ 화면의 **굵게** 표기는 마크다운 미지원 상태이므로 그대로 노출하거나, 지원 여부를 알려줘.)
- 목록으로 / 수정 / 삭제(확인창) 버튼, 이전글·다음글(없으면 "이전 게시물이 없습니다.").

[작성/수정]
- 필드: 구분 태그(필수), 필독 체크박스, 제목(필수), 작성자·작성일(읽기 전용, 작성일은 오늘 날짜), 내용(필수).
- 수정 화면은 기존 값을 채워서 진입, 취소 시 상세/목록으로 복귀, 필수값 검증 후 저장.

[디자인]
- 브라운 계열(#5c4033 톤) 포인트 컬러, NOTICE 세리프 타이틀과 하단 라인, 둥근 카드형 UI, 날짜·조회수는 모노스페이스.
- 반응형 지원.

[산출물]
- 파일 구조와 localStorage→Firebase 전환 시 교체할 부분을 마지막에 간단히 정리해줘.


[ 공지사항 구현후 연계 수정하기 ]
-공지사항 게시글 중 상위 3개 게시물을 별도의 박스로 구성하여 사이트 상단에 고정하고 한줄 출력하기.내용은 3개의 게시물이 순서대로 넘어감 (멈춤,플레이,닫기버튼 포함)
-index페이지에서 필요한 기능이야. 그리고 notice 출력 내용은 중앙정렬이야. 닫기버튼 등 컨트롤파트는 오른쪽 정렬이야.
-index페이지 상단 출력은 최상단을 말한거야. 메뉴보다 위에 출력되게해. 닫으면 메뉴는 최상단으로 올라가야겠지.

추가수정: 상단 notice 박스가 닫으면 전체 아래 박스가 위로 올라와야하는데 지금 보면 메뉴만 위로 올라와. 이 박스가 body바로 아래 와서 전체 박스를 밀도록해. 메뉴도 같이 밀려야하는 것은 기본이야.
