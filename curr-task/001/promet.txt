**히어로 섹션 바이브 코딩 프롬프트**
실제로 사용된 이미지는 images/used 폴더에 있는 이미지를 사용해주세요.

```
[공통]
- 히어로 섹션은 배경이미지(고양이 사진)가 꽉 찬 박스. background-size: cover; center.
- 높이는 100vh (모바일은 100svh 권장). 이미지 위에 상단 헤더가 오버레이됨.
- 헤더 텍스트/아이콘은 배경 위에 얹히므로 가독성 확보 (필요시 상단 그라데이션 오버레이).
- 슬라이더 구조: 슬라이드 4개, 좌우 화살표 버튼 + 하단 인디케이터(페이지네이션 바).
- 화살표 버튼과 인디케이터는 슬라이드가 바뀌어도 위치가 변하지 않도록
  슬라이드 컨테이너 밖에서 position: absolute(또는 fixed)로 히어로 박스 기준 고정.
  (슬라이드 트랙 안에 넣지 말 것)
- 인디케이터: 활성 항목은 갈색(#6b4a32 계열) 가로 막대(pill), 비활성은 연한 회색 작은 점.
  하단 중앙 배치, 슬라이드 변경 시 활성 상태 전환.

[데스크탑 (769px 이상)]
- 헤더: 3분할 구성
  - 좌측: 텍스트 메뉴 "APPAREL / 굿즈 / 커뮤니티" 가로 나열
  - 중앙: 로고 "그루밍데이" (굵은 한글 텍스트 로고)
  - 우측: 아이콘 4개 (검색, 마이페이지, 장바구니(수량 뱃지 + "+1,000P" 말풍선 툴팁), 언어/지구본)
- 좌우 패딩 넉넉하게(약 100px), 헤더 높이 약 130px.
- 화살표 버튼: 화면 좌우 가장자리 세로 중앙 (top: 50%; translateY(-50%)).
- 이미지는 와이드 비율, 고양이가 중앙~좌측에 오도록 object-position 조정.

[모바일 (768px 이하)]
- 헤더 2단 구성:
  - 1행: 좌측 햄버거 메뉴 + 마이페이지 아이콘 / 중앙 로고(더 작게) / 우측 검색 + 장바구니 아이콘
  - 2행: 가로 카테고리 메뉴 "APPAREL, 굿즈" 좌측 정렬 + 우측 끝에 원형 "+" 버튼 (메뉴 더보기/펼침)
- "커뮤니티", 언어 아이콘, 포인트 말풍선은 모바일에서 숨김 (햄버거 메뉴 안으로 이동).
- 좌우 패딩 약 15px, 헤더 전체 높이 축소.
- 이미지는 세로형 비율, 고양이 얼굴이 중앙에 크게 보이도록 object-position 조정.
- 화살표 버튼은 크기 축소 또는 유지하되 좌우 가장자리 고정, 인디케이터는 하단 중앙.

[미디어쿼리]
- 모바일 우선이 아닌 데스크탑 기본 스타일 작성 후
  @media (max-width: 768px) { ... } 로 모바일 오버라이드.
- 헤더는 데스크탑/모바일 마크업을 따로 두거나, 하나의 마크업을 CSS grid/flex 재배치로 전환.
- 768px 기준으로 헤더 레이아웃, 로고 크기, 메뉴 표시 여부, 패딩, 이미지 위치만 변경하고
  슬라이드 동작 로직(JS)은 공통으로 유지.
```

**팁:** 바이브 코딩 시 "화살표/인디케이터는 슬라이드 트랙과 분리된 고정 레이어"라는 점과 "768px 이하에서 헤더가 1행→2행으로 바뀐다"

[ 메뉴 바이브 코딩 프롬프트 ]

[동작]
- 모바일(768px 이하)에서 헤더 좌측 햄버거 버튼 클릭 시 왼쪽에서 오른쪽으로 슬라이딩하며 등장.
- 드로어 안의 X 버튼 클릭 시 다시 왼쪽으로 슬라이딩하며 사라짐.
- 구현: 드로어는 position: fixed; top: 0; left: 0; height: 100%;
  기본 transform: translateX(-100%) → 열림 상태(.is-open) translateX(0),
  transition: transform 0.3s ease.
- 열렸을 때 body 스크롤 잠금(overflow: hidden).
- 드로어는 히어로/헤더보다 위 레이어(z-index 최상단).
- 접근성: 열릴 때 aria-expanded, aria-hidden 토글, ESC 키로 닫기.
- 768px 초과(데스크탑)에서는 드로어와 햄버거 버튼 모두 display: none.

[레이아웃 - 전체 폭 흰 배경, 세로 스크롤 가능]
1. 상단 영역 (연한 회색 배경 #f4f5f7, 패딩 약 30px 30px)
   - 좌측: 타이틀 "로그인 해주세요" (굵게, 약 18px) + 아래 서브텍스트
     "회원가입하고 다양한 혜택을 받으세요." (회색, 약 14px)
   - 우측: X 닫기 버튼 (얇은 선 아이콘)

2. 버튼 3개 영역 (좌우 패딩 30px, 가로 3등분 flex, gap 약 6px)
   - "로그인" / "회원가입" / "주문조회"
   - 흰 배경 + 연한 회색 테두리(1px) + 둥근 모서리(약 4px), 높이 약 40px, 텍스트 중앙
   - "회원가입" 버튼 위에 갈색(#6b4a32 계열) 말풍선 뱃지 "+1,000P"
     (흰 글씨, 작은 둥근 박스, 아래쪽 꼬리 삼각형, 버튼 상단에 걸쳐 position: absolute)

3. 메뉴 리스트 (버튼 영역과 간격 넉넉히 약 40px)
   - "APPAREL", "굿즈", "커뮤니티" 세로 나열, 굵은 텍스트 약 18px, 항목 간격 약 20px
   - "커뮤니티"만 우측 끝에 아래 방향 화살표(chevron) 아이콘 → 클릭 시 하위메뉴 아코디언 펼침
     (펼침 시 chevron 180도 회전)

4. 언어 선택 (메뉴 아래 간격 약 40px)
   - 태극기(한국), 성조기(미국) 국기 아이콘 가로 나열, 약 30px 크기, 클릭 시 언어 전환

[주의]
- 드로어 너비는 화면 전체(100%) 또는 최대 약 450px, 이미지 기준으로는 거의 전체 폭.
- 뒤쪽 배경 딤(dim) 처리는 이미지상 없으므로 생략 가능 (필요하면 반투명 오버레이 추가).
- 드로어 내부 메뉴 구성(커뮤니티, 언어, 로그인 관련 버튼)은 앞서 말한 헤더에서 모바일에 숨긴 항목들이 이동한 곳임.
